# Actual native LVGL UI capture

Run `python3 scripts/native-ui/build.py --lvgl <pinned LVGL 9.3 source directory> --cjson <ESP-IDF components/json/cJSON directory>`. Add `--before` to compile Git baseline `b32b57ce0027bf20e7e73a86fa7dc4e2ff0784df` (override with `--baseline`) with the same fixtures. No display service, browser, network, or real device is required. The output uses the native RGB565 software renderer and production UI source.

The test uses static host display buffers and a 16 MiB allocator arena so desktop assertions cannot hang while rendering; it reports actual LVGL heap use rather than treating arena size as used memory. This is not a firmware heap configuration change. Candidate assertions check bounds and 48-pixel clickable targets; synthetic actions and ESP/BSP functions are stubbed. Device FPS, transport effects, and calibrated physical touches require a separately approved device test.

See `docs/native-device-ui-candidate.md` for validation and deployment limits. PNG conversion can use macOS `sips -s format png file.ppm --out file.png` or any lossless PPM converter.

The candidate harness also models a 211 ms busy display lock and verifies that the periodic microphone meter skips the busy update with zero lock wait, then resumes after release. It compiles the production UI function and needs no audio or device.

The browsing fixtures are generated by the production Calendar scene director with synthetic events only. Native captures include the exact status/local menu, paginated Calendar, details, stale/empty/revoked/unconnected/error/loading states and long titles. Twenty interrupted browsing/reentry passes route every visible native clickable control; existing Music/confirmation regressions remain enabled. Run with the backend dependency Python environment.

The modern revision uses a native icon tile launcher and open agenda. The Calendar scene director supplies its timezone-correct date as the first subtitle line; no ESP clock assumption is made. `backend_protocol_fixture.py` generates synthetic actual-backend ownership transitions for native replay, and `test_transport.py CJSON_DIR` tests the real WebSocket assembler.

The all-screen metadata audit injects generated diagnostic sentinels through native entrypoints and checks recursive visible labels, preserving arbitrary user text and required credits/errors/setup/confirmation content. It also verifies content visibility after Calendar-to-Music/Memory/empty-state transitions, rather than checking only stored label text. It runs only on the candidate, not `--before`.

Recovery audit: 528 repeated microphone/voice failure, busy-display delivery, recovery and navigation checks across 11 scenes. Notices must fit in the reserved top strip, overlap no visible root object, and preserve content. Synthetic recovery-calendar-mic/voice, protected-both and music-voice captures are emitted.
